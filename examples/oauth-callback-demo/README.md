# Демо: зачем ngrok этому проекту

В репозитории есть примеры входа через Google (`express-gdata` и другие).
После нажатия «Разрешить» Google отправляет человека **обратно в приложение**
по адресу вроде `/google_cb`.

Если приложение запущено на удалённом компьютере (например, в Cloud Agent),
адрес `http://localhost:3000` открывается только *там*, а не у вас дома.
**ngrok** делает обычную интернет-ссылку на этот локальный сервер —
её можно открыть в браузере и проверить «возврат» после входа.

## Как запустить

```bash
# 1. Демо-сайт
node examples/oauth-callback-demo/server.js

# 2. В другом терминале — публичная ссылка
bash .ngrok/expose.sh
```

Ключ ngrok настраивается один раз:
https://dashboard.ngrok.com/get-started/your-authtoken  
`ngrok config add-authtoken ВАШ_ТОКЕН` (в чат токен не присылайте).

Откройте выданную `https://…ngrok…` ссылку → «Сымитировать вход через Google».
